# 99-IDEAS is closed

New ideas go to `03-SEEDS/` as faceted notes. See `03-SEEDS/README.md` and
`00-FOUNDATION/Facet-Vocabulary.md`.

The files still in this folder — `Interactives.md`, `Practice-Tools.md`, `Stories.md`,
`Scale-Beam-Tool.md` — hold real ideas that have **not** been migrated. They are kept, not
archived, precisely because archiving them would lose things quietly. Several of the lines
in `Interactives.md` are live threads hiding in a list nobody opens: the Large Number Plane,
the traversal and graph-theory work, trigonometry via the unit circle, and the three
"out of scope" perception items that turned out to be one Lab.

**Migration is opportunistic, not a project.** When a session touches one of these ideas,
that idea becomes a seed and the line is struck from the legacy file. When a legacy file
empties, it goes to `99-ARCHIVE/`. Nobody sits down to migrate all of them; that task would
never be done and would produce worse seeds than writing them when they matter.
