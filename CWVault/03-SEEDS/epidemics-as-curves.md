# Epidemics, as curves above the line

Michael, 30 Sept 2026: the Time Machine can simulate epidemics. In the shape of the tool, an epidemic is a *curve* (Time-Machine-Shape.md): cases or deaths by year, a file in `stories/curves/` with its source and how sure it is, and a word in the column, like People. Candidates: cholera in the nineteenth century, the 1918 influenza, smallpox before and after vaccination. The simulation — a model she can run, not a record — is a different thing and would be a bench on the plane first. Undecided: which comes first, the record or the model.
